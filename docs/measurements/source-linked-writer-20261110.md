# 生成側の原文参照プロトコルへの変更

f02a529で収納ベンチeditorialを2通信、同商品standardを2通信、防臭袋editorialを1通信。計5通信、入力9800・出力8268。前回までの4通信18200を含め計9通信36268トークン。全て確認済み消費。元の不採用記録・未完了記録は保持。

収納ベンチのeditorialは再生成後も不合格。standardは機械チェックを通ったが「足元もすっきり見えます」が原文で立証されず、独立実務評価で不合格としたため旧転記型AI審査への追加送信は行わなかった。防臭袋は『レジ 処理』などの検索語を用途へ誤読した。両方式とも本体へ採用していない。文番号審査は生成が通らず、この5通信では実際には呼び出していない。

原因は、生成モデルによる引用の部分選択漏れと、検索語を性能・用途の根拠に使うこと。editorialだけ原文の連続箇所に番号を割り当て、モデル出力はsourceId/sourceIdsを選択する方式へ変更。サーバーは元の連続文字列に厳密対応付けし、既存product/sentences/quotesへ戻す。文の書換え・出力への引用補完・単位変換・商品別例外は行わない。全原文は切らず保持する。明示ラベル『検索用キーワード』『商品補足説明』以降は検索語セクションとして引用候補にしないが、資料全体からも削除しない。これは構文上の位置付けであり、残した箇所の商品本体への帰属や意味を承認するものではない。元の機械拒否と独立審査は維持。

生成の公開用契約は同じだが、モデルへ送る内部JSONスキーマはstandard/guidedと異なる。この違いを比較監査にも明示し、同一スキーマだと報告しない。出力上限3000・モデル120B/medium・元原文・既存上限は維持。固定ベンチの初回予約推定7254、防臭袋6142。いずれも実使用量・現在残量の保証ではない。

非通信検証は中核679件、既存回帰458件成功。新方式の文章品質とGroq受理はまだ未検証。本体への採用根拠にはしない。
