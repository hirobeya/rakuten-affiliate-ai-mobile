# ウレナビ 2週間自己検証基準

目的は中止判断ではなく、ウレナビを「ツールなし」「ChatGPT無料版」より明確に速く・楽にするための改善基準とする。

## 比較する3条件
1. ツールなし：楽天市場・ROOM等を通常操作し、自分で商品選定・理解・投稿文準備を行う。
2. ChatGPT無料版：商品情報を自分でChatGPTへ渡し、比較・理解・投稿文を作る。
3. ウレナビ：商品発見→比較→選定→理解→投稿文→投稿準備をウレナビで行う。

## 同じ課題で比較する
- 同一日に、可能な限り同じ商品テーマ・目的・価格条件を使う。
- 1回の課題は「投稿に使う1商品を決め、ROOM用投稿文をコピーできる状態にする」まで。
- Threads／Instagramは本実装後、同一商品から追加生成する時間を別計測する。

## 必須計測
- 開始から候補表示までの秒数
- 候補比較から商品決定までの秒数
- 商品理解に要した秒数
- 投稿文完成までの秒数
- 投稿準備完了までの総秒数
- タップ／コピー／画面移動など主要操作回数
- 手入力文字数
- 商品情報を別アプリへ移す回数
- 投稿文の修正回数
- 事実誤りの有無
- 『なぜこの商品を選ぶか』を自分で説明できるか

## 販売前の改善基準
- ウレナビは総時間だけでなく、主要工程の大半でChatGPT無料版より短いこと。
- ChatGPTより遅い工程があれば、その工程を特定して改善してから再測定する。
- 事実誤り、根拠外の便益、商品取り違えは0件を維持する。
- 文章だけ速くても、商品発見・比較・選定・理解が遅ければ合格としない。
- ヒロの運営側手作業を必要とする仕組みは採用しない。
- iPhoneだけで完結しない工程は改善対象とする。

## 日々の記録単位
1回ごとに以下を保存する。
- 日時
- 条件（toolなし/chatgpt/urenavi）
- 検索テーマ
- 選んだ商品
- 各工程の秒数
- 総秒数
- 操作回数
- 修正回数
- 事実誤り
- 面倒だった工程
- 次に削る操作

## 2週間終了時に出す結論
中止／継続の判定ではなく、次の4点を決める。
1. ChatGPTより遅い工程
2. 最も時間を削れた工程
3. 販売前に必ず直す工程
4. ウレナビだけの明確な優位性としてLPに書ける事実
