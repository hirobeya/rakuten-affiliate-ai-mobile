## 決定事項（変更には明示承認が必要）
- 新規契約は **月額1,480円／単一プラン**。税の表示方式・税区分はStripe設定と表示で別途照合する。980円・既存Base→Proアップグレードを新規販売経路に使わない。
- 課金価格は単に環境変数のPrice IDを信用せず、Stripe read-only参照で active / JPY / 1480 / monthly / quantity 型を照合する。
- 既存顧客の契約・権限は自動移行しない。新規契約受付を止めている間はその状態を維持する。
- 本番Stripe・本番Supabase・本番Vercel・mainへの変更は個別の明示承認なく行わない。
- AI実測は隔離環境、Free条件、各通信の承認・停止・証拠・予算が成立した場合だけ開始。未確認なら停止する。
