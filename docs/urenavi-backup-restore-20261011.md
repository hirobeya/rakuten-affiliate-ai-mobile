# 売上・手動活動の端末移行

現在のアカウントの売上・手動活動を形式識別子付きJSONで表示・コピーし、別端末へ貼り付けて復元できる。全アカウント情報、認証情報、APIキーは含めない。

追加件数を確認し、本人の記録であることを確認して復元する。入力編集・アカウント切替後の古い確認は使えない。復元時にも最新保存データと照合する。同日売上が異なる場合は全体を拒否し上書きしない。完全一致する活動は重複排除。不明とゼロを保持。保存は一回の書込みであり、保存失敗による部分取り込みはない。2MBを超える貼付けは拒否する。

検証：node --test tests/*.test.js の244件成功。vercel-build成功。既存のapp.htmlインラインJS構文検証も成功。実機の貼付け・クリップボード・認証後の画面操作は未確認。

未完成：商品別台帳・交流候補の復元、クラウド同期、iPhone実機検証、楽天商用データ許可、無料Groq実商品実測、採算実測。今回のバックアップは売上・手動活動のみである旨を画面に明記。課金・本番・mainは変更しない。
