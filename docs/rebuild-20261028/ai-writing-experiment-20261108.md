# ウレナビ AI文章制作能力への対処・2026年11月8日

## この変更で扱う二つの事実

* 原文抽出・ジャンル補助・ルール追加を検証したが、固定44商品の通常生成数は5→6のまま、6軸品質は単独編集判定で2/44のまま。固定780商品でも通常ローカル完了8件。ルール増加だけでは十分な訴求文を作れていない。
* ChatGPTが対話で作れていたような、商品情報から利用意図・訴求の切り口を選び自然な日本語へ仕上げる能力は、現在の固定規則中心ローカル生成にはない。モデルの本来の文章能力を使う比較経路が必要。ただし「モデルに任せたら品質が保証される」とは言えない。

## 技術的判定

この実験は、生成AIの文章制作能力を比較するための**実装経路を用意した**のであって、通常生成の高品質化を実現した証拠ではない。特に実モデルを使った6軸品質の前後差、構造化JSON成功率、トークン消費、free制限との整合、1生成当たりの費用は未測定。

Groqに送信するには別途、現在の同一組織・全callerの残量、永続claim/使用量台帳、JSON strict、モデルの最大トークン/出力上限、追加レビュー送信の予算などの安全条件が必要。今回の操作は実Groqリクエスト0。これまでの別SHAの限定承認は流用しない。費用不明な場合は送信しない。

**次の意思決定**：安全な実モデル比較が認可されて初めて、同一商品でstandardとeditorialを同じモデル・出力上限・本体情報で比較し、審査前の提出JSON成功、独立レビュー・6軸、根拠外0、使用量を別々に測る。良質な文章が再現性をもって改善しないなら採用しない。固定ローカル生成の限界自体をこの実験で解消したと主張しない。
