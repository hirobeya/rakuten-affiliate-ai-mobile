## 技術的に不足する部分

1. **商品識別の一般化**：固定語彙やタイトル抽出で多数の未知商品を識別できない。ジャンルは補助証拠であり、それだけでは対象／付属品／販売セットの意味関係を確定できない。
2. **説明文の所有者・適用条件の意味解析**：captionには別売品、関連商品、モデル違い、店の宣伝が混在する。単語一致や原文引用の存在だけで商品本体の証拠にすると虚偽紹介につながる。
3. **特徴から購入理由への意味生成**：仕様を拾うだけでは読者の用途・機能との関係・選ぶ理由を構築できない。ソースの述語や因果関係を読解し、意味上妥当な推論だけ採用する必要がある。
4. **多様で自然な日本語の作文能力**：現行のルール／候補採点は生成AIの自由な文章制作能力を持たない。ルールを増やすだけで同等の品質になる根拠はない。
5. **品質評価の独立性**：機械的ready、6軸評価、未知商品の盲検評価、実際のユーザー判断を混同しない。合格テストの増加を訴求力改善と見なさない。
6. **API経済性**：Groqを通常失敗の自動的な逃げ道にすると使用量制約に反する。別のモデル/ローカル推論を採る場合にも、推論速度、iPhone可用性、メモリ、月額1,480円での採算が実測で必要。
