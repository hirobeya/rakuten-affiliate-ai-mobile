## 優先順位

### Gate A: 生成中核の品質実証（最優先）

同一商品の原文から標準/編集者/ガイド付きの文章を比較する。6軸（理解、具体性、選ぶ理由、対象と価値、自然さ、根拠外0）を独立審査し、合格文のみ後段のコピー契約に通す。固定44商品だけで最適化せず未見商品も必須。契約に反するもの、モデル違い、別売や条件落ちは即拒否。原文不足の場合に黙って作話しない。テスト件数を品質向上と読み替えない。

### Gate B: 利用量・費用・同時利用の成立

Free上限で実測し、モデル呼出、JSON400、再審査・途中失敗、月額1,480円での原価と契約者増加時の予算を同時に評価する。毎分/毎日/モデル・アカウントの枠、他caller、過去未精算/予約、無条件429停止、永続claim/監査を確認。利用者がいないという申告を現在残量のAPI観測と混同しない。新しいSHAと許可条件がない限り実通信なし。

### Gate C: UI ⇄ API ⇄ 購読者の真正な一周

iPhone Safariで、ログイン→検索→商品比較・採用→通常/量産→根拠付き承認済コピー→楽天ROOMへ投稿準備→投稿確認/取消→実績記録→ブラウザ離脱復帰を確認。owner Previewだけでなく有料契約者の権利分離、他アカウント混入なし、無料ユーザーによるコピー利用不可を別に確認する。Productionへの拡大は品質・セキュリティ・費用のゲート通過後、別の明示的な採用判断を必要とする。

### Gate D: 発売判定

商品理解の幅／文章の魅力／根拠外0／通信失敗時の挙動／iPhoneでの完了／収益性／購読者隔離の同時達成を証明してから採用する。現在の実測はローカル ready 6/44、単独編集6軸全pass 2/44で未合格。支払い画面やPreviewがREADYでも発売完了とはしない。
