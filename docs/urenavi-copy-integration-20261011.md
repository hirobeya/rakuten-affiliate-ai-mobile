# ウレナビ改：文章契約統合と原価計測

## 実装した経路
- アプリのPreview呼出先を `/api/room-copy` に統合。
- owner / Preview限定。本番では404。旧 `/api/room-ai-v3` の単体処理・テスト経路は変更していない。
- 安全に完成できる商品は既存 `localZeroCall` をそのまま再利用し、Groqを呼ばない。ローカル結果は検証済みの既存V3契約を保持する。存在しないacts_onを捏造して新契約に見せない。
- AIが必要な商品は既存room-semantic-engine/providerの確定product{what,acts_on,acts_on_quote} / sentences[{text,kinds,quotes}]で生成。機械拒否と全文章の固定5質問・全体品質検証を通ったものだけ公開。
- クライアントはcanonical専用アダプタで、machine/review双方合格・完全な契約・本文とvariantの一致を確認する。未完成・不一致・unclearはコピー不可。
- 検証済み結果は元商品名・説明・schema・モデルに一致するサーバーキャッシュから再利用。モデルが異なる同時要求は統合しない。

## 停止・再開
- 一回のHTTP内で進めるのは、待機不要の別ステージのみ。自動ポーリング・待機タイマー・429再試行はない。
- 利用枠による待機が必要なら202で未完成にし、残り商品も一旦停止。「確認を続ける」の本人操作で保存済みステージから再開。
- 429で後続商品は停止。通信復帰・認証復帰で自動再開しない。
- 検索復元には状態のヒントだけを保存。未検証の文章をブラウザ保存から完成扱いにしない。

## 原価計測
- 実provider応答のinput/prompt tokensとoutput/completion tokensを生成・検証それぞれ記録。推論tokenをcompletionへ二重加算しない。
- 利用者識別はログ内のハッシュ。メールやAPIキー、商品原文を原価ログに出さない。
- GPT-OSS 120B / 20Bの2026-10-11公式価格表と実token数からUSD換算推定。請求確定金額ではない。モデル価格やusageが不明ならnull。失敗の原価を0と断定しない。
- ローカル処理と当該HTTPでproviderを呼んでいないキャッシュ応答の追加AI原価は0。
- 実利用のログ収集・月次集計、為替、ホスティング/DB/決済費、保守負担は今後の実測項目。料金1,480円の採算が成立したとは報告しない。
