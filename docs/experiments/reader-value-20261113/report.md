# ウレナビ｜「自然だが欲しくならない」への購入理由実験

実施日：2026-11-13。ベース：PR #170（Draft）。作業ブランチ：`experiment/urenavi-reader-value-20261113`。

## 前提：ユーザー評価

PR #170の自然文について「前よりはまし」「② 自然にはなったけど、商品を欲しいと思うほどではない」と評価。
従って次の主目的は「機械判定の通過率」ではなく「特徴が利用者の生活と結び付くこと」。

## 分析

前方式は末尾に「確認して選べます」「特徴です」の反復があり、読み手が選ぶ理由を自分事として理解する手掛かりが乏しい。抽出と出版ガードを変えず、検証専用の読者視点コピーを1回比較する。

## 実装

- `lib/urenavi-core/reader-value-draft.js`：既存の独立した原文根拠取得方式を再利用するオフラインの文章実験。既存本体とAPIには接続しない。
- 取得元・位置・引用が一致しない文章は保留。
- 文章を「読み手の状況→商品特徴→判断材料」に変更。事実と、読み手への問い掛けを混同しない。
- `publication:false`, `copyable:false`, `semanticApproved:false`を固定。
- ただし現実には4つの利用関係ごとの構成が残っており、**汎用性を実証できていない**。その点は未解決である。
