## 入力の原本性

- `source.js`: itemCode / itemName / itemCaption / catchcopy / itemPrice と、明示した既取得属性だけを複写します。画像のバイナリ・画像URL配列は送りません。除外属性名を記録します。itemCaption内のHTMLは原文として保持しますが、画像の取得やimage_url型のモデル入力は行いません。
- HTML、改行、CRLF、空白、Unicode、モデル別の説明、注意書きは加工しません。JSONエンコードは復号後に完全一致する可逆処理です。
- 原文の要約、文分割、独自の事実台帳はモデル入力に使いません。HTMLはデータのままで、ブラウザに実行可能な形で表示する処理もありません。
- 元フィールドごとのSHA-256、選択入力全体のsourceHash、送信userメッセージのinputHash、requestHashと整形履歴を記録します。
- 入力18,000 UTF-8 bytes超過、または推定入力＋出力2,000が8,000超過なら、切捨てず保留します。推定トークン数は実測でも残容量でもありません。
- 保存済み商品データは取得時点の入力保持検証に使用しています。データセット全体を未加工の最新楽天APIレスポンスと認定していません。

## 1通信の出力契約

モデル `openai/gpt-oss-120b`、reasoning_effort `low`、出力上限2,000、画像なし。Strict JSON Schemaは以下を分けます。

- product: 販売本体の原文表記、販売単位またはnull、原文引用。
- hold: 保留状態と理由。保留時はpost=null。
- post.sentences / notes / tags: すべて同じ文章契約。text、fact/scene、モデル等のscopeまたはnull、fieldと連続した原文quoteを必須にします。

根拠は位置番号をモデルに生成させず、サーバが原文中に実在するか照合します。原文の全文・前後関係は引き続きモデルへ渡し、引用だけに置換しません。モデルの引用や自己申告は意味的正確性の証明にはしません。

## 全文検証と意味評価

`verify.js` は本文、注記、タグを同じ在否・数値単位・限定・程度・時点・部位・宣伝表現の拒否処理へ通します。モデルラベルの対象は原文の引用位置と前後から確認します。引用の末尾から隣のモデルを取り込まない境界テストを追加しています。

旧V4のように引用全体の条件を無条件に要求せず、主張の語と関係する節を調べます。数値の主張と無関係な比較条件など、関係を機械的に確定できないものは未確認として残します。承認へ読み替えません。

前回のS3原本を変更せず、新契約へテスト内だけで変換し、モデル別仕様の一般化、程度の強化、指の範囲拡大、集計時点欠落、信頼の証、単位推測の拒否を確認します。過去に実測済みの商品は再送対象から除外します。これは文章生成の商品別例外ではなく、保存された送信履歴による重複禁止です。

**機械検査の通過は `needs_independent_review` です。** 全文・原文・販売本体/単位・全文章ID・ハッシュ・6品質軸・8意味関係を独立審査パケットへ出します。新たなGroq審査通信はありません。既定では審査担当者がいないため未承認のままです。

人間の独立審査を行う場合だけ、信頼するサーバ側依存 `reviewer={kind:'human',id,evaluate}` を渡します。商品データや生成JSONから担当者・承認を取得してはいけません。source/draft/displayのハッシュ、全文の対象ID、6軸と意味関係の全評価、評価者・理由が一致しなければ不承認です。テストの評価者はスタブであり実際の人間による品質評価ではありません。

審査後もこの隔離モジュールの publication/copyable は常にfalseです。本体採用は別途判断します。広告表記・改行・タグ・注記込み500文字を検証します。

## 新ルート専用の通信制御

`safety.js` は新しい `raw-source-fallback-live-v1` 承認を要求します。旧S3初回承認・旧環境フラグ・旧予約は使用しません。新承認も今回は作成していません。

承認は隔離実験環境、実行SHA、sourceHash、requestHash、最大1通信、再試行0、有効期限60秒以内へ結び付けます。実行時の有効な制限、残容量、使用量不明なし、排他条件、新実験予算が不足・未確認なら送信しません。残容量のnullを0や満額に置換しません。RPDを日次トークン残容量として扱いません。独自の分間通信数・消費量と実験上限も確認します。

`audit.js` は新規の `raw-source-fallback-v1` ディレクトリだけを明示的に作成できます。自動で旧ストアを発見・移行・精算しません。既存ディレクトリへの新規作成は拒否します。

- 送信前: 排他ロック、商品単位の一度限りの要求記録、入力原本・ハッシュ・SHA・予約をfsyncして保存。
- 送信後: 実測入力/出力/合計トークン、応答時間、原文・生成内容・全文機械判定・容量観測を別ファイルに一度だけ保存。
- 独立評価: 評価済み/未評価の状態を別ファイルへ保存してからロックを解放。
- 429、通信不明、使用量不明、予約超過、JSON失敗、不完全応答、容量ヘッダー欠落は停止し、記録・ロックを保持。
- 保存失敗時も再送しません。同じ商品は原文や生成条件が変わっても再送できません。

`createTransport` は将来の隔離実行用の固定Groq HTTPアダプタです。キーは引数で安全なプロセスメモリから明示的に受け取るだけで、環境変数の探索やキー発行・出力・保存はありません。リダイレクトと自動再試行は禁止です。
