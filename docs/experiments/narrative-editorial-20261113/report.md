2026-11-13。既存エンジン、既存の`grounded-local-recovery-v2`、本番、課金、認証、DBは変更していない。

## 設計を変えた点

従来の「選ぶポイント→仕様です→商品説明には→比較して選べます」という説明調の定型句を捨て、**原文根拠に結び付いた具体的な特徴から書き始める**。複数の確実な特徴の関係を組み立て、必要なときは注意事項を優先する。

`lib/urenavi-core/narrative-editorial.js` に独立実装。`generate(item,{experimentalNarrativeDraft:true})` のみ使用可能。生成しても `publication:false` / `copyable:false` / `semanticApproved:false`、検証専用。Groq呼び出しなし。
