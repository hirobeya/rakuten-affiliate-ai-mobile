# 旧実績のアカウント分離と移行

旧売上・活動は端末共通キーだった。今後の読書きをアカウント別データへ統合し、自動で旧データを表示・帰属させない。

- 初回に旧記録の日数・活動件数・日付衝突を表示。本人確認後のみ現在アカウントへ一度だけ取り込む。
- 元のキー・元の値を保持。取り込みと帰属確定は単一localStorage書込みで行い、保存失敗で片方だけ進まない。
- 同日売上衝突は上書き拒否。活動はtype/at/day/noteの完全一致で重複除外。
- 帰属確定後は別アカウントへ再取り込み不可。元データのJSONバックアップを表示・コピー可能。
- 日別売上・活動の表示・追加・コピーをログイン中のアカウントへ限定。商品別台帳とは別集計。
- 活動CSVの行区切りを実改行に修正。

Groq無料枠の方針を追記。原価ログのestimatedUsdは定価換算参考値で請求額ではない。usagePlanPolicy=free、estimateMeaningで意味を明記し、請求額は未確認のためchargedUsd=null。Groqのプラン・鍵・Vercel環境変数は変更しない。429停止、後続停止、自動再試行禁止を維持。

検証：全347テスト・vercel-build成功。新規テストで分離・一度限り・元記録保持・衝突・重複・原子的保存失敗・破損保全・無料方針ログを確認。iPhone実機・認証後Preview操作は未確認。
