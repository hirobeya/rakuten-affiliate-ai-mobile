# 投稿済み商品の重複防止と商品別成果

## 実装した流れ
- 商品検索・選定→検証済みROOM文のコピー→コピー済み台帳→楽天ROOMで本人が投稿→投稿完了を明示的に記録。
- コピーを投稿完了として扱わない。ROOMへ自動投稿しない。
- itemCodeまたは楽天の正規商品URLで同一商品を識別。商品名の類似で誤って統合しない。URLの広告パラメータは識別に使わない。
- 投稿済み商品は検索表示・候補表示と生成対象から除外。投稿済み記録の取り消しで再選定可能。
- 商品別に日付・売上・報酬・販売件数・作業時間を本人確認済みの値だけ保存。不明はnull、ゼロと区別。同じ商品・日付の修正は置換し、二重加算しない。
- 同じ日付に報酬と正の作業時間の両方が記録された範囲のみ、観測報酬／作業1時間を比較。将来予測や活動の因果効果を断定しない。
- 端末内・ログインアカウント別保存、履歴（最新50商品表示）、JSONバックアップ。サーバー取得・楽天連携は行わない。

## 検証
識別・URL安全性、コピーと投稿の区別、重複・取り消し、別アカウント分離、再読み込み、保存失敗、不明とゼロ、訂正二重加算、日付、観測比較の欠測除外、app inline script構文をテスト。
