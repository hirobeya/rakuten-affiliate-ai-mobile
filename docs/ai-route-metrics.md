# ウレナビ AI経路計測

スーパー・ウレナビでは、Groq節約率ではなく「必要な箇所だけGroqを使えているか」を確認するため、商品理解の経路を次の4種類で計測する。

- `cache`: 商品理解キャッシュから取得。Groq呼び出し 0。
- `local`: 許可型ローカル判定で確定。Groq呼び出し 0。
- `text`: Groqテキスト解析を実行。Groq呼び出し 1。
- `image`: Groqテキスト後に画像解析まで実行。Groq呼び出し 2。

ログ名は `urenavi ai route` に統一し、少なくとも `route`, `groqCalls`, `cacheStatus`, `mode` を記録する。トークン使用量とレート制限情報が取得できる場合は併記する。

最終的なKPIはGroq呼び出し数だけでなく、固定30件の刺さり評価と固定780件の安全性評価を同時に見る。節約のためにコピー品質を落としてはならない。
