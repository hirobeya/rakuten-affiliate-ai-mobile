# iPhoneショートカット試作：スクショ → 文字化 → ウレナビ

## 目的
楽天市場アプリ等で利用者自身が表示したランキングページ／商品ページのスクリーンショットを、iPhone内で文字情報へ変換し、画像を原則ウレナビへ送らずに投稿準備へ進む。

## ショートカット名
ウレナビに送る

## 推奨構成
1. 「共有シートに表示」をON。
2. 受け入れる入力タイプを「画像」にする。
3. 画像から文字を抽出するアクションを追加する。
   - iPhone上の表示名はOSの言語・版により「画像からテキストを抽出」「テキストを認識」等の表記差があり得る。
4. 抽出した文字を「クリップボードにコピー」する。
5. URLアクションに、試作Previewの `shortcut-prototype.html` を指定する。
6. 「URLを開く」を追加する。

## 利用手順
1. 楽天市場アプリ等でランキングページまたは商品ページを表示。
2. スクリーンショットを撮る。
3. 写真アプリ等から共有 → 「ウレナビに送る」。
4. ショートカットが画像内文字を抽出し、クリップボードへコピー。
5. ウレナビ最小画面を開く。
6. 「ショートカットでコピーした文字を貼り付け」をタップ。
7. 「候補を整理して投稿準備」をタップ。
8. ROOM投稿文をコピーする。

## この方式の重要点
- 通常経路では画像をウレナビへ送らない。
- 楽天市場ページをウレナビのサーバーから取得しない。
- スクレイピングをしない。
- 有料機能の試作経路では楽天ウェブサービスAPIを使わない。
- サーバーへ送るのは利用者端末が抽出した文字情報のみ。
- サーバーは受信文字列を永続保存しない試作仕様。
- AI出力は受信文字列に存在する事実のみを根拠とし、OCR誤認が疑われる場合は警告扱いにする。

## 画像認識失敗時の将来fallback
最初の試作では実装しない。
楽天から書面回答を得た後、必要な場合のみ「画像を一時送信→OCR/AI処理→即時破棄」を別経路として追加する。
保存は行わない。

## 自己検証で計測する区間
- スクリーンショット撮影からショートカット起動まで
- 文字抽出完了まで
- 最小画面への貼り付けまで
- 候補整理完了まで
- ROOM投稿文コピーまで

ChatGPT無料版より遅い区間があれば、その区間を優先して削る。
