# 今日のROOM運用の統合

ホームの次の行動を投稿・生成・交流・確認済み日別実績から決定する。429停止→生成中→確認待ち/手動停止/復元未確認→コピー済み投稿未確認→交流待ち→生成失敗→実績未入力→商品選び。提案は実際の記録状況に基づき、需要・売上・因果効果の推測をしない。対象パネルへ移動するリンクを用意。0と未入力・未取得を区別。商品または交流の読み込み失敗なら確認が必要と表示。

交流履歴を候補へ戻すundoが新規登録時の重複防止を通らなかったため、同じ相手・同じ活動の別候補または対象日の完了がある場合は拒否。単一書込み前の判定で履歴・候補を維持。異なる日のいいね履歴とフォローの相手単位重複規則は維持。

比較スコアの表示を「売れやすさ」から「選定比較指標」へ変更。計算・順位・生成契約は変更しない。根拠のない成約優先の文言を、用途・価格・根拠の比較へ置換。

検証：node --test 全372件、vercel-build成功。ホーム実関数はDOMスタブで、投稿未確認優先・実績0/未入力・破損表示を確認。交流undo重複拒否・履歴保持を確認。

実ブラウザで最新Previewを開いた結果はVercelサインイン画面。ローカルVercel CLI認証は利用できない。Deployment Protectionは変更せず、以前失敗したGoogleログインの繰り返しは実施しない。HTTPコネクターでの配信検証と、実ブラウザ認証後の操作検証を区別する。iPhone、実商品Groq、商用データ許可、採算は未完了。
